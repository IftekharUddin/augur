# Policy Review: Hearthstone Battlegrounds

Review performed against the checklist in
[game-policy-review.md](game-policy-review.md). Every source was retrieved on
**2026-08-30**; each is cited with the date printed on the document itself
where the publisher provides one.

**This document records findings and analysis. It does not record a
conclusion.** `games/hearthstone-battlegrounds/game.yaml` keeps
`policy_review.status: pending` until the maintainer decides, because the
decision is a risk judgment about other people's accounts, not a technical
finding. What the maintainer is deciding, and the options, are in the
`DECISION NEEDED` brief on the review issue.

Nothing here is legal advice.

## What Augur actually does, stated precisely

The review is only meaningful against an exact description of the behavior, so:

- Captures pixels from a single game window using operating-system capture
  APIs, with the user's explicit permission, scoped to the window the user
  selected.
- Sends those frames to a model provider to extract structured state, and
  returns text advice to the user.
- Does **not** read the game's process memory.
- Does **not** read, write, or enable any game log file.
- Does **not** write any file into the game's installation directory.
- Does **not** send input to the game, hook it, inject into it, or interact
  with it in any way other than reading the pixels the operating system is
  already compositing to the screen.
- Does **not** interact with anti-cheat systems or attempt to avoid detection.

The absence of input synthesis and memory reading is enforced by
`tests/architecture/augur_no_input_synthesis.rs`, not merely asserted here.

## Findings

### 1. The EULA's prohibitions, and which one actually bites

Blizzard End User License Agreement, last revised **March 21, 2024**
([source](https://www.blizzard.com/en-us/legal/fba4d00f-c7e4-4883-b8b9-1b4500a402ea/blizzard-end-user-license-agreement),
retrieved 2026-08-30). The relevant definitions in section 1.C.ii:

- **Cheats**: "methods not expressly authorized by Blizzard (whether
  accomplished using hardware, software, a combination thereof, or otherwise),
  influencing and/or facilitating gameplay, including exploits of any in-game
  bugs".
- **Bots**: "any code and/or software, not expressly authorized by Blizzard,
  that allows the automated control of a Game, or any other feature of the
  Platform".
- **Hacks**: "accessing or modifying the software of the Platform in any manner
  not expressly authorized by Blizzard".

Section 1.C.vi separately prohibits **data mining**: "Use any unauthorized
process or software that intercepts, collects, reads, or 'mines' information
generated or stored by the Platform". The same section notes that "Blizzard
may, at its sole and absolute discretion, allow the use of certain third-party
user interfaces."

Augur is clearly not a **Bot**: it never controls the game, and the
architecture test makes that structural rather than aspirational. It is
arguably not a **Hack**: it neither accesses nor modifies the game's software,
and this is precisely why the no-log-file decision below matters.

The clause that bites is **Cheats**, and it bites on four words: *influencing
and/or facilitating gameplay*. Read literally, that covers any tool that helps
a player play better, including a piece of paper. It cannot be read literally,
or the deck-tracker ecosystem Blizzard has tolerated for a decade would be
prohibited. So the operative question is not what the text says in isolation
but where Blizzard has actually drawn the line in practice, which is finding 3.

The **data mining** clause is the second live one. Screen capture reads pixels
the operating system composites for display; whether that is "information
generated by the Platform" is genuinely arguable. It is a weaker fit than log
reading, which is squarely within it.

### 2. The Anti-Cheating Agreement adds little, and is old

Blizzard Anti-Cheating Agreement, last updated **February 3, 2016**
([source](https://www.blizzard.com/en-us/legal/simple/cd5930c0-2784-420c-a23d-1e0d6ff8599b/anti-cheating-agreement),
retrieved 2026-08-30). Prohibits third-party software that enables cheating or
botting, that allows a user to "modify or 'hack' a Blizzard game's user
interface, environment, and/or experience in any way not expressly allowed",
and that "intercept[s], mines or otherwise collects information from or through
Blizzard games".

It describes the anti-cheat utility as scanning game RAM, active processes, the
Windows process list, and Windows handles identifying processes that access the
game. Augur does none of the things that scanning looks for; it does not open a
handle to the game process at all.

The "modify the user interface, environment, and/or experience" language is
worth noting for the **overlay** feature specifically (Milestone 2). An
always-on-top window that draws over the game does not modify the game's user
interface in any technical sense, it composites above it, but the phrase
"and/or experience" is broad. The same phrase would equally cover every
streaming overlay and every deck tracker.

### 3. Blizzard's official position is: they will not tell you

Blizzard Support, "Is Third Party Software Allowed?"
([article 13078](https://us.support.blizzard.com/en/article/13078), retrieved
2026-08-30; the page renders client-side and its text was read via search
indexing rather than direct fetch, so treat the wording as reported rather than
quoted). The substance is that players should read the Anti-Cheating Agreement
before installing add-ons or mods, and that **Customer Support cannot confirm
whether a particular piece of software is allowed**.

This is the most important finding in the review and it deserves to be stated
plainly: there is no route by which Augur can obtain an authoritative yes.
Waiting for official clarity is not a strategy, because the publisher's
documented position is that it does not give clarity. Any decision here is a
risk decision taken without the publisher's confirmation.

### 4. The tolerated precedent is strong, and closer to Augur than expected

- **Hearthstone Deck Tracker** reads Hearthstone's log output rather than
  process memory, and has been distributed publicly for roughly a decade with
  no enforcement action reported against its users. Blizzard staff have said so
  informally: Ben Brode, "any app that duplicates what you can do with a pencil
  and paper already is fine"; Zeriyah (community manager), "It's not against
  the TOS"
  ([HearthSim FAQ](https://github.com/HearthSim/Hearthstone-Deck-Tracker/wiki/FAQ),
  retrieved 2026-08-30). These are forum and interview remarks, not written
  policy, and neither is binding.
- Blizzard shipped a **native deck tracker in the mobile client in 2024**,
  which is at minimum a signal that the category is accepted.
- **Bob's Buddy** is the precedent that actually matters for Augur, and it is
  specific to Battlegrounds. Distributed with Hearthstone Deck Tracker since
  April 2020, it reads the current board state and runs "upwards of 10,000"
  simulated combats to display live win, loss, and tie probabilities during the
  combat phase
  ([announcement](https://articles.hsreplay.net/2020/04/24/introducing-bobs-buddy/),
  [help article](https://help.hearthsim.net/en/articles/4106635-how-do-i-get-bob-s-buddy-to-show),
  both retrieved 2026-08-30).

Bob's Buddy matters because it is not a pencil-and-paper tool. It performs
computation the player demonstrably cannot do unaided, in real time, in
Battlegrounds specifically, and presents the result as an in-game overlay. It
has run publicly for over six years without reported enforcement. If the
pencil-and-paper framing were the real line, Bob's Buddy would be over it.

### 5. A correction to this repository's own checklist

The checklist in `game-policy-review.md` describes Hearthstone Deck Tracker as
reading `Power.log` "with log output officially togglable", implying Blizzard
provides a supported in-game switch for it.

**I could not verify that, and the evidence points the other way.** The
documented mechanism is that the tracker writes a `log.config` file into the
Hearthstone directory to enable the debug logging it needs
([HearthSim setup guide](https://github.com/HearthSim/Hearthstone-Deck-Tracker/wiki/Setting-up-the-log.config),
retrieved 2026-08-30); the HearthSim FAQ describes this as enabling
"Hearthstone's debug-logging 'feature'", scare quotes theirs. I found no
Blizzard patch note, support article, or in-game setting exposing log output as
a supported option.

That difference is not cosmetic. Writing a configuration file into the game's
installation directory to turn on a debug facility is a much weaker claim to
authorization than flipping a switch the publisher provided, and it sits closer
to the **Hacks** definition ("accessing or modifying the software of the
Platform") than the checklist assumed. The checklist should be corrected.

Augur is unaffected in practice, because it does not use log files at all, and
this finding is a reason to keep it that way.

### 6. Where Augur is *further* from the line than the tolerated precedent

- It never writes to the game directory, and never enables a debug facility.
  Hearthstone Deck Tracker does both.
- It never opens a handle to the game process, so the anti-cheat utility's
  documented scans have nothing to find.
- It reads only what the operating system already composites to the screen,
  under a permission the user grants to the operating system, and which the
  user can revoke without Augur's cooperation.

### 7. Where Augur is *closer* to the line than the tolerated precedent

This is the honest other half, and it is the part that makes the decision
non-obvious.

- **It recommends actions.** Bob's Buddy reports a probability and leaves the
  decision to the player. Augur says "buy this, sell that, and here is why".
  Against "influencing and/or facilitating gameplay", recommending a specific
  action is a stronger fit than reporting a computed statistic, even though the
  underlying capability gap is arguably smaller.
- **It is general-purpose.** The tolerated tools are purpose-built by known
  community developers with a long public track record. A general screen-reading
  AI coach is a newer category with no track record, and publishers have
  historically reacted to categories rather than to individual tools.
- **The overlay (Milestone 2)** engages the "modify the ... experience" language
  in the Anti-Cheating Agreement, in the same way every streaming and tracker
  overlay does, but with less precedent behind it.
- **Frames leave the machine.** Augur transmits game imagery to a third-party
  model provider. No clause found in this review addresses that directly, and
  the tolerated trackers do transmit game data to their own services
  (HSReplay), but the shape is different and it is worth flagging rather than
  assuming it is covered.

## Open questions this review did not resolve

- Whether Blizzard treats screen capture as "reading information generated by
  the Platform" under the data-mining clause. No enforcement history either way
  was found.
- Whether any published Blizzard position on AI-assisted play exists as of
  August 2026. Searching found none; absence of evidence here is weak evidence,
  since a policy could exist in a channel not indexed.
- Whether Battlegrounds specifically, as a competitive ranked mode with a
  leaderboard, is treated differently from constructed play. Not addressed in
  any source found.

no anti-cheat circumvention, and no gameplay input, regardless of how the terms
are read.
